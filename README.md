# 🗜 CompresorPRO

Compresor multi-formato **gratuito y open source** para Windows.

## ✨ Características

- Soporta **LUC (LZMA extremo), ZIP, 7Z, TAR, TAR.GZ, TAR.BZ2, TAR.XZ**
- Comprime archivos y **carpetas completas**
- Interfaz moderna con **tema claro y oscuro**
- **Contraseñas AES-256** para ZIP y 7Z
- **Búsqueda dentro** de archivos comprimidos sin extraerlos
- Historial, perfiles y **drag & drop**
- Sin publicidad, sin rastreo, sin cuentas
